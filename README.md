# AI Cover Letter Generator (Level 1)

## 🚀 Project Overview

The **AI Cover Letter Generator** is a beginner-friendly web application that helps users generate a professional cover letter by filling out a simple form.

This project focuses on **UI design, form handling, and simulating AI behavior** using a mock function instead of a real AI API.

---

## 🎯 Mission Objective

**Mission 4: AI Cover Letter Generator**

Theme:
- AI Integration (Simulated)
- Prompt Engineering (Conceptual)
- SaaS-style UI development

Goal:
- Capture user inputs
- Generate a professional cover letter
- Display it in a copy-friendly format

---

## 🧩 Difficulty Level

### ✅ Level 1 – Beginner Requirement

This level **does NOT use any real AI API** (OpenAI / Gemini).
Instead, it simulates AI output using a predefined template.

---

## 🖥️ Features

- Professional input form
- Fields:
  - Candidate Name
  - Job Role
  - Company Name
  - Key Skills
- Mock AI cover letter generation
- Clean output display
- Copy to Clipboard functionality
